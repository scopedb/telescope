# v0.3.0 (unreleased)

These are draft release notes. Publish artifacts only after the release checks pass; do not move a published tag.

## Highlights

- Rebuild Telescope as a focused OpenTelemetry Collector distribution for delivering OTLP logs, traces, and metrics to user-managed ScopeDB tables.
- Add explicit per-signal table mappings plus `inspect`, `preview`, `plan`, and `validate` workflows for reviewing the ingestion contract before rollout.
- Add persistent queue recovery, retry-safe row isolation, live capture, delivery verification, ingestion status, Prometheus alerts, and single-statement ScopeQL diagnostics.
- Adopt ScopeDB Go SDK v0.7.0 and Go 1.26.10, preserve v0.2 table mappings, stop automatic unknown replay, and expose unknown counts.
- Add a Kubernetes StatefulSet baseline, multi-architecture container images, and release archives for macOS arm64 and Linux amd64/arm64.

## Breaking changes

- Replace the v0.2 `path`, `schema_version`, and `create_tables_if_not_exist` exporter fields with explicit `signals.<signal>.table` and `signals.<signal>.mapping` configuration.
- Use the Collector batch processor for batching; `sending_queue.batch` is unsupported so final delivery accounting can follow each queued request.
- Rename `telescope daemon` to `telescope run` and move the raw Collector command to `telescope advanced collector`.
- Remove the previous application-layer server. Operational health, status, capture, verification, and query commands remain available.
- Move the reusable exporter from `packages/scopedbexporter` to `scopedbexporter`. Custom distributions use `NewFactory` and the v0.3 configuration types; the append client and intermediate records are private.

## Upgrade

Do not replace a v0.2 binary in place while its persistent queue contains telemetry. Drain the v0.2 queue under its original configuration, prepare and validate an explicit v0.3 mapping, then deploy v0.3 with a new queue volume before moving OTLP traffic.

See the complete [v0.2 to v0.3 migration procedure](../migration-v0.2.md).
