# AGENTS

## Repository Rules

- Pull requests use semantic PR titles.
- Use `type: summary` or `type(scope): summary`.
- Recommended types: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`, `ci`, `build`, `perf`, `revert`.
- Commits do not need to follow a semantic format.

## Examples

- `feat: add persistent queue deployment defaults`
- `fix(exporter): classify 401 as permanent`
- `docs: explain ScopeDB table initialization`
